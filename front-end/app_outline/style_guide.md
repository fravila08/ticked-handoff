# Style Guide: Ticked

- **Vibe:** a clean paper planner. Calm, tidy, satisfying to tick things off. Not a generic SaaS dashboard.
- **Mobile-first:** design for a 390px-wide phone; it should still look intentional on desktop (centered column, max ~560px, or a two-column layout on wide screens).
- **Colors:** off-white paper background, ink-navy text, ONE fresh accent (e.g. a highlighter green or a marker blue) used only for primary actions and the checkmark. Tags get soft, muted colors. Overdue dates and errors use a red that is clearly different from the accent.
- **Type:** a friendly, slightly rounded display face for headings and the app name; a highly readable sans for task titles and body text. Dates in a tabular-figures style so they line up.
- **Task rows:** checkbox on the left (at least 44px tap area), title, then a small line underneath with project · due date · tags. Done tasks get a line through and fade a little.
- **Touch targets:** at least 44px tall. Primary buttons ("Save task", "Create project") full-width on mobile.
- **Motion:** subtle and quick. The checkmark draws itself when ticked; a new task slides in at the top. Respect reduced-motion.
- **Navigation:** bottom tab bar on mobile (Tasks · New · Projects), highlights the current page.
- **Accessibility:** visible keyboard focus, labels on every input, real checkboxes (not divs), contrast AA or better.
